# 📡 日淘任意门 · 万能多品类捡漏雷达

自由添加任意想买的商品（笔记本、相机镜头、手机平板、游戏掌机、耳机、手办潮玩、鞋服手表、通用二手），自动监控雅虎日拍、**深查正文排雷暗病**、换算真实落地到手价，并在发现真漏时通过 **Bark / ntfy / 微信 / 飞书** 自动推送到手机。

---

## 核心亮点
1. **自助添加/管理任意商品（电脑 + 手机都能直接改）**：
   - 监控列表独立保存在 [profiles.json](profiles.json)，默认内置 **💻 东芝 Dynabook G83（13/12/11代）**；
   - **电脑本地版**（`http://127.0.0.1:8783`）：点 **`➕ 添加/管理商品`** 填名称/模板/关键词/预算，一键 **`☁️ 同步到 GitHub 云端`**；
   - **手机网页版**（GitHub Pages）：点 **`➕ 添加/管理商品`**，填入仅保存在你本机浏览器的 GitHub 仓库 Token 后，**直接在手机上增删商品并立刻触发云端扫描**。
2. **8 套品类模板 + 专属日文正文排雷引擎**：
   - 自动避开「退货免责条款」和「なし/ありません」否定句误报，精准拦截：
     - 💻 笔记本：铰链断/缺盖、碎屏/白斑、键盘连击、BIOS 锁、电池鼓包
     - 📷 相机镜头：发霉（カビ）、起雾（クモリ）、脱胶、AF/快门故障，自动提取快门数
     - 📱 手机平板：网络锁（赤ロム）、ID 锁、碎屏/烧屏、面容故障，自动提取电池健康度
     - 🎮 游戏掌机：摇杆漂移（ドリフト）、BAN 机、读卡故障、按键失灵
     - 🎧 耳机音频：单耳无声、杂音、断连、电池衰减
     - 🧸 手办潮玩（默认竹蜻蜓包税 0 关税）：缺件、断件粘修、发粘、疑似散货、无盒
     - 👟 鞋服箱包手表（默认竹蜻蜓包税）：加水分解开胶、破洞、污渍、手表停走
     - 📦 通用二手：故障、拆机件、严重破损、未测动作
3. **24 小时免费云端巡检 + 手机推送**：
   - 通过 GitHub Actions 错峰自动巡检，发现达标好价（一口价或 3 小时内结拍且正文无硬伤）立刻推送到 **Bark / ntfy / PushPlus / 飞书 / 钉钉**，点通知直达日淘任意门！

## 快速启动
- **Windows 本地版**：双击 `启动雷达.bat`，浏览器自动打开 `http://127.0.0.1:8783`。
- **云端版**：仓库开启 GitHub Pages（`main` / `/docs`），在仓库 `Settings → Secrets → Actions` 添加 `BARK_URL`（或 `NTFY_TOPIC` / `PUSHPLUS_TOKEN`）。
